建立一個名為 `my-first-io.js` 的檔案。

撰寫一個程式，使用一次**同步**的檔案系統操作讀取一個檔案，並把該檔案包含的換行符號（\n）數量印到終端機（標準輸出 stdout），就像執行 `cat file | wc -l` 一樣。

要讀取的檔案的完整路徑會作為第一個命令列參數提供（即 process.argv[2]）。你不需要自己製作測試檔案。

## 提示

要執行檔案系統操作，你需要 Node 核心程式庫中的 `fs` 模組。要載入這類模組，或者其他任何「全域」模組，請使用下面這段咒語：

```js
const fs = require('fs')
```

現在，你就可以透過名為 `fs` 的變數使用完整的 `fs` 模組了。

`fs` 模組中所有同步（或阻塞）的檔案系統方法都以 'Sync' 結尾。要讀取一個檔案，你需要使用 `fs.readFileSync('/path/to/file')`。這個方法會*回傳*一個包含檔案完整內容的 `Buffer` 物件。

`fs` 模組的文件可以透過瀏覽器開啟以下網址來閱讀：
  {rootdir:/docs-nodejs/fs.html}

`Buffer` 物件是 Node 高效表示任意資料陣列的方式，無論這些資料是 ascii、二進位還是其他格式。`Buffer` 物件可以透過直接呼叫它們的 `toString()` 方法轉換成字串。例如 `const str = buf.toString()`。

`Buffer` 的文件可以透過瀏覽器開啟以下網址來閱讀：
  {rootdir:/docs-nodejs/buffer.html}

如果你在找一個計算字串中換行符號數量的簡單方法，請回想一下：JavaScript 的 `String` 可以用 `.split()` 分割成子字串陣列，而 '\n' 可以用作分隔符號。注意，測試檔案最後一行的末尾沒有換行符號（'\n'），所以用這個方法你得到的陣列會比換行符號數量多一個元素。

執行下面的命令來檢查你的程式是否正確：

```sh
$ {appname} verify my-first-io.js
```

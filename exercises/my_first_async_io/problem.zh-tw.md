建立一個名為 `my-first-async-io.js` 的檔案。

撰寫一個程式，使用一次**非同步**的檔案系統操作讀取一個檔案，並把該檔案包含的換行符號數量印到終端機（標準輸出 stdout），就像執行 `cat file | wc -l` 一樣。

要讀取的檔案的完整路徑會作為第一個命令列參數提供。

# 提示

這道題的解法*幾乎*和上一道題一樣，只是現在你必須用**Node.js 的方式**來做：非同步。

不要用 `fs.readFileSync()`，而要用 `fs.readFile()`；也不要使用這個方法的回傳值，而要從你作為第二個參數傳入的回呼函式中取得這個值。想了解更多關於回呼函式的內容，請參考：https://github.com/maxogden/art-of-node#callbacks。

記住，符合 Node.js 慣用風格的回呼函式通常有這樣的簽名：

```js
function callback (err, data) { /* ... */ }
```

所以你可以藉由檢查第一個參數是否為真值來判斷是否發生了錯誤。如果沒有錯誤，第二個參數應該就是你的 `Buffer` 物件。和 `readFile()` 一樣，你可以把 'utf8' 作為第二個參數傳入，把回呼函式作為第三個參數，這樣你得到的就是 `String` 而不是 `Buffer`。

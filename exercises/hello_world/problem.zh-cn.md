## 提示

要编写一个 Node.js 程序，你只需要创建一个后缀名为 `.js` 的文件，然后开始写 JavaScript！用 `node` 命令来运行你的程序，例如：

```sh
$ node hello-world.js
```

和浏览器中一样，你可以用同样的方式向终端输出内容：

```js
console.log('text')
```

当你完成后，需要运行：

```sh
$ {appname} verify hello-world.js
```

来进行后续步骤。你的程序将会被测试，并生成一份测试报告；如果你成功通过测试，本课程将会被标记为 “completed”（已完成）。

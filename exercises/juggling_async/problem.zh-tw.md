建立一個名為 `juggling-async.js` 的檔案。

這道題和上一道題（HTTP COLLECT）相同，都需要使用 `http.get()`。不過這次，你會收到**三個** URL 作為前三個命令列參數。

你必須收集每個 URL 提供給你的完整內容，並把它印到終端機（標準輸出 stdout）。你不需要印出長度，只要以字串形式印出資料；每個 URL 一行。關鍵在於，你**必須**按照這些 URL 作為命令列參數提供給你的順序印出它們。

----------------------------------------------------------------------
## 提示

別指望這三台伺服器會好好配合！它們不會照你希望的順序給你完整回應，所以你不能天真地在拿到輸出時就印出來，因為它們的順序會亂掉。

你需要把結果排隊，並追蹤有多少個 URL 已經回傳了它們的全部內容。只有當你拿到全部內容後，才能把資料印到終端機。

計算回呼函式被呼叫的次數是 Node 中管理非同步的基礎方法之一。除了手動去做，你可能會覺得依賴 [`async`](https://www.npmjs.com/package/async) 或 [`run-parallel`](https://www.npmjs.com/package/run-parallel) 更方便。但在這道練習中，請不要用它們來完成。

執行下面的命令來檢查你的程式是否正確：

```sh
$ {appname} verify juggling-async.js
```

创建一个名为 `juggling-async.js` 的文件。

这道题和上一道题（HTTP COLLECT）相同，都需要使用 `http.get()`。不过这次，你会收到**三个** URL 作为前三个命令行参数。

你必须收集每个 URL 提供给你的完整内容，并把它打印到终端（标准输出 stdout）。你不需要打印长度，只需要以字符串形式打印数据；每个 URL 一行。关键在于，你**必须**按照这些 URL 作为命令行参数提供给你的顺序打印它们。

----------------------------------------------------------------------
## 提示

别指望这三台服务器会好好配合！它们不会按你希望的顺序给你完整响应，所以你不能天真地在拿到输出时就打印，因为它们的顺序会乱掉。

你需要把结果排队，并跟踪有多少个 URL 已经返回了它们的全部内容。只有当你拿到全部内容后，才能把数据打印到终端。

对回调函数计数是 Node 中管理异步的基础方法之一。除了手动去做，你可能会觉得依赖 [`async`](https://www.npmjs.com/package/async) 或 [`run-parallel`](https://www.npmjs.com/package/run-parallel) 更方便。但在这道练习中，请不用它们来完成。

运行下面的命令来检查你的程序是否正确：

```sh
$ {appname} verify juggling-async.js
```

创建一个名为 `filtered-ls.js` 的文件。

编写一个程序，打印出指定目录下的文件列表，并按文件扩展名过滤。你的程序会收到一个目录名作为第一个参数（例如 '/path/to/dir/'），以及一个用于过滤的文件扩展名作为第二个参数。

例如，如果第二个参数是 'txt'，那么你需要把列表过滤成只包含**以 .txt 结尾**的文件。注意，第二个参数_不会_带有 '.' 前缀。

请记住，你的程序所收到的第一个参数并不是 `process.argv` 数组的第一个值，因为前两个值被 Node 保留用于系统信息。

文件列表应该打印到终端，每行一个文件。你**必须**使用异步 I/O。

## 提示

`fs.readdir()` 方法的第一个参数是路径名，第二个参数是回调函数。回调函数的签名是：

```js
function callback (err, list) { /* ... */ }
```

其中 `list` 是一个由文件名字符串组成的数组。

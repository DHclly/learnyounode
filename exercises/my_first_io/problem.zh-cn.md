创建一个名为 `my-first-io.js` 的文件。

编写一个程序，使用一次**同步**的文件系统操作读取一个文件，并把该文件包含的换行符（\n）数量打印到终端（标准输出 stdout），就像运行 `cat file | wc -l` 一样。

要读取的文件的完整路径会作为第一个命令行参数提供（即 process.argv[2]）。你不需要自己制作测试文件。

## 提示

要执行文件系统操作，你需要 Node 核心库中的 `fs` 模块。要加载这类模块，或者其他任何"全局"模块，请使用下面这段咒语：

```js
const fs = require('fs')
```

现在，你就可以通过名为 `fs` 的变量使用完整的 `fs` 模块了。

`fs` 模块中所有同步（或阻塞）的文件系统方法都以 'Sync' 结尾。要读取一个文件，你需要使用 `fs.readFileSync('/path/to/file')`。这个方法会*返回*一个包含文件完整内容的 `Buffer` 对象。

`fs` 模块的文档可以通过浏览器访问以下地址来查看：
  {rootdir:/docs-nodejs/fs.html}

`Buffer` 对象是 Node 高效表示任意数据数组的方式，无论这些数据是 ascii、二进制还是其他格式。`Buffer` 对象可以通过直接调用它们的 `toString()` 方法转换成字符串。例如 `const str = buf.toString()`。

`Buffer` 的文档可以通过浏览器访问以下地址来查看：
  {rootdir:/docs-nodejs/buffer.html}

如果你在找一个计算字符串中换行符数量的简单方法，请回想一下：JavaScript 的 `String` 可以用 `.split()` 分割成子字符串数组，而 '\n' 可以用作分隔符。注意，测试文件最后一行的末尾没有换行符（'\n'），所以用这个方法你得到的数组会比换行符数量多一个元素。

运行下面的命令来检查你的程序是否正确：

```sh
$ {appname} verify my-first-io.js
```

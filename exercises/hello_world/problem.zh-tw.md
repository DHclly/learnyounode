## 提示

要撰寫一個 Node.js 程式，請建立一個副檔名為 `.js` 的檔案，然後開始撰寫 JavaScript！用 `node` 命令來執行你的程式，例如：

```sh
$ node hello-world.js
```

和瀏覽器中一樣，你可以用同樣的方式將內容輸出到終端機：

```js
console.log('text')
```

當你完成後，必須執行：

```sh
$ {appname} verify hello-world.js
```

才能繼續。你的程式將會被測試，並產生一份報告；如果你成功通過測試，本課程將會被標示為「completed」（已完成）。

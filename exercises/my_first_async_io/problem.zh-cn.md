创建一个名为 `my-first-async-io.js` 的文件。

编写一个程序，使用一次**异步**的文件系统操作读取一个文件，并把该文件包含的换行符数量打印到终端（标准输出 stdout），就像运行 `cat file | wc -l` 一样。

要读取的文件的完整路径会作为第一个命令行参数提供。

----------------------------------------------------------------------
# 提示

这道题的解法*几乎*和上一道题一样，只是现在你必须用**Node.js 的方式**来做：异步。

不要用 `fs.readFileSync()`，而要用 `fs.readFile()`；也不要使用这个方法的返回值，而要从你作为第二个参数传入的回调函数中取得这个值。想了解更多关于回调函数的内容，请查看：https://github.com/maxogden/art-of-node#callbacks。

记住，符合 Node.js 惯用风格的回调函数通常具有这样的签名：

```js
function callback (err, data) { /* ... */ }
```

所以你可以通过检查第一个参数是否为真值来判断是否发生了错误。如果没有错误，第二个参数应该是你的 `Buffer` 对象。和 `readFile()` 一样，你可以把 'utf8' 作为第二个参数传入，把回调函数作为第三个参数，这样你得到的就是 `String` 而不是 `Buffer`。

`fs` 模块的文档可以通过浏览器访问以下地址来查看：
  {rootdir:/docs-nodejs/fs.html}

```sh
$ {appname} verify my-first-async-io.js
```
